## 🚀 About Me

I am a **Software Engineer** specializing in **Full-Stack Web Architectures** and **Agentic AI Systems**, driven by a passion for building robust, scalable products that merge deep engineering logic with intuitive design.

- 💼 **Current Role**: Building scalable enterprise solutions and modern full-stack web applications at **[Meetri Infotech](https://www.meetri.in/)**.
- 🤖 **Agentic AI & LLMs**: Architecting autonomous agents, tool-calling pipelines, and multi-agent systems leveraging **LangChain**, **LangGraph**, and **Model Context Protocol (MCP)**.
- 🌟 **Open Source Leadership**: Honored to be an **LFX '23 Mentor & Mentee** within the Cloud Native Computing Foundation (CNCF) ecosystem with **[Layer5](https://layer5.io/)** / **[Meshery](https://meshery.io/)**.
- 🎨 **Engineering x Design**: Former Visual Designer at **Layer5**, bringing deep empathy for design systems (Sistent), component accessibility, and refined visual craft.
- ⚡ **Continuous Evolution**: Actively exploring agent memory architectures, production RAG pipelines, microservices, and AI evaluation frameworks.
